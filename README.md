# MyNotes

记录工作中学习到的知识，沉淀可复用的经验与思考。

这里的笔记主要来自与 AI 对话后的总结，也包括实践中的理解、问题排查过程和经验积累。希望把零散的讨论整理成清晰的文档，方便日后检索、回顾和继续完善。

## 内容范围

- 工作中接触的技术概念、原理与方法。
- 与 AI 讨论后整理的知识总结。
- 问题分析、排查过程与解决方案。
- 实践经验、工具使用和阶段性思考。

## 文档约定

- 使用 Markdown（`.md`）编写，以中文为主。
- 所有笔记存放在 `notes/` 目录下，暂不在其中创建分类子目录；仓库说明和写作约定保留在根目录。
- 每篇笔记聚焦一个主题，使用清晰、便于检索的文件名。
- 优先记录自己的理解、适用条件与实践结论，必要时附上参考来源。
- 随着学习和实践持续修订；AI 生成的内容需结合可靠资料或实际验证审视。

## 笔记写法

- 每篇笔记必须记录日期，统一使用 `YYYY-MM-DD` 格式。
- 首先描述遇到的问题。背景可以简洁，但必须完整交代问题产生的场景、要完成的事情以及遇到的困难，让读者理解为什么会有这个问题，不能让问题看起来凭空产生。
- 然后描述针对这个问题，我学到的解决方法和相关知识，记录自己的理解与思考。
- 整体采用个人笔记的风格，以自己的学习过程和收获为主线。

可以参考以下结构，按实际内容灵活展开：

```markdown
# 笔记标题

日期：YYYY-MM-DD

## 遇到的问题

我在什么场景下想完成什么事情，遇到了什么困难，为什么需要解决这个问题。

## 学到的解决方法与知识

针对这个问题，我学到了什么方法、它为什么适用，以及我对相关知识的理解。
```

## 使用方式

直接浏览 [notes/](notes/) 目录下的 Markdown 笔记，或通过 GitHub 搜索查找感兴趣的主题。

这是一个持续积累的个人知识仓库。笔记反映记录时的理解，欢迎通过 Issue 讨论和指正。
